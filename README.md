# Mosaic

## Install dependencies

```sh
bun install
```

## Run development server

```sh
bun dev
```

## Create an .env file

```sh
# Clerk
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=

# Supabase
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=

# LemonSqueezy
LEMONSQUEEZY_API_KEY=
NEXT_PUBLIC_LEMONSQUEEZY_MYNA_URL=
```
